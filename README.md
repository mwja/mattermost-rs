# mattermost-rs

A Rust `gpui` client for Mattermost, because Electron is soooooo 2020.

The code is split into 3 crates:
- `mattermost`: The Rust SDK for interacting with Mattermost, and the `Resource`
  trait to implement for the app
- `mattermost-desktop`: The GPUI desktop client for Mattermost.
- `gpui-tokio-bridge`: Simple helper inspired by Zed to run a GPUI app with
  `tokio` async.

## Feature Parity
The end goal is full feature parity with the official desktop client. Once
necessary functionality is achieved, the app may move to `0.1.0`. Once
feature parity is achieved, the app may move to `1.0.0`.

## Running
The app is in active development, and may not always compile. Tags will
eventually be provided as well as releases for stable releases. For now, you can
clone and run `cargo run --release`.


## Building from source
On Mac, you need the Metal ToolChain, if you don't already
```sh
xcodebuild -downloadComponent MetalToolchain 
```

Then you must set a your code signing details in `.env`, as the example shows.


## Versioning

Pre-0.1.0, every patch must be assumed to be breaking. Post 0.1.0, every patch
should add functionality and every minor will be a breaking change for the SDK.

Post 1.0.0, I will likely track the SDK and the app on two different versions,
and will follow regular semver.
